# iPhone での確認チェック表（Phase 1A・デザイン刷新版）

`01-windows-setup.md` の手順で Expo Go にアプリを表示してから確認してください。
各項目の結果を ○ / × で記録し、× の項目はスクリーンショットを添えて Claude に送ってください。

> Expo Go で確認できる範囲です。BLE測位は Phase 1B（Apple Developer Program 登録後）に確認します。
> 地図は iPhone 標準の Apple マップを使います。屋外の地図の表示には通信が必要です（施設の屋内図は通信がなくても表示されます）。

## A. 地図・屋外の機能（サーバー未接続でも確認できます）

| # | 操作 | 期待される結果 | 結果 |
|---|---|---|---|
| A1 | アプリを開く | Apple マップの上に【サンプル】テストモールの屋内図（色分けされた店舗区画・通路・壁）が表示される | |
| A2 | 上部の「現在地を使いますか？」で「許可する」→ iPhone の確認で「アプリの使用中は許可」 | 青い点（現在地）が地図に表示される（屋内図から遠い場合は見えない場所にある） | |
| A3 | 右側の「現在地」ボタン（照準アイコン） | 地図が現在地へ移動する。Google マップのように道路や建物の地図が見える | |
| A4 | 2本指で縮小していく | ある程度縮小すると屋内図が消え、施設の位置が青いピンで表示される。ピンをタップすると施設へ戻る | |
| A5 | 下部の「施設への経路」→「Apple マップ」または「Google マップ」 | 地図アプリが開き、施設（南口）までの経路が表示される | |
| A6 | 検索欄に住所や駅名（例：「東京駅」）を入れて「地図で探す」→ 結果をタップ | その場所へ地図が移動しピンが立つ。下部の「ここへの経路」で地図アプリが開く | |
| A7 | 検証 →「サンプル施設を現在地へ移動」→ 地図画面に戻る | 施設が現在地のすぐ北側に表示され、「施設に入りました」と表示される（屋内・屋外の自動切替） | |

## B. 屋内の機能

| # | 操作 | 期待される結果 | 結果 |
|---|---|---|---|
| B1 | 右側の「施設全体を表示」ボタン（ビルのアイコン）→ 拡大 | 店舗名が表示される。トイレ・エレベーター・エスカレーター・出入口のアイコンが見える | |
| B2 | 右側の「2F」「1F」 | フロアが切り替わる。2F は中央に「吹き抜け」とフードコートがある | |
| B3 | 上部の「飲食」 | 飲食店だけが色濃く表示され、下に一覧（12件）が出る。一覧をタップでその店舗へ | |
| B4 | 検索欄に「かふぇ」 | 「カフェ・テスト（飲食・1F）」が出る。タップで店舗カード（営業中／営業時間外の表示つき） | |
| B5 | 地図上の店舗区画を直接タップ | その店舗のカードが出る | |
| B6 | 店舗カードの「ここへ行く」 | 「参考案内になります」の確認 →「参考案内を表示」で青い経路と、所要時間・案内文（例「1F 南口から出発 → 約98m 進む → 到着」） | |
| B7 | 2Fの店舗（例「らーめん」で検索 → ラーメン・テスト）へ「ここへ行く」 | 案内文に「エスカレーターで2Fへ」。「1Fの経路」「2Fの経路」でフロアごとの経路を表示 | |
| B8 | 上部の「トイレ」 | 出発地から一番近いトイレへの経路が出る | |
| B9 | 屋内図の通路（灰色の部分）をタップ | 「出発地を…指定した地点にしました」と表示され、青い丸が移動する | |
| B10 | 上部の赤／黄色の帯をタップ | 地図データの版と規制情報の取得時刻が表示される | |
