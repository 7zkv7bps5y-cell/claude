## 2. Apple Developer Program

### 2-1. なぜ必要か

- BLE測位と MapLibre（ネイティブ地図）は、Expo Go では動きません。iPhone で確認するには「開発ビルド」という専用アプリを作って iPhone に入れる必要があります。
- Windows PC からは、クラウドでビルドするサービス（EAS Build）を使います。クラウドで作ったアプリを iPhone に入れるには、Apple の有料登録が必要です（Mac があれば無料の方法もありますが、今回は Mac がない前提です）。

### 2-2. 費用

| 項目 | 内容 |
|---|---|
| 年会費 | 99米ドル／年（調査時点の円換算で約14,000〜15,000円。日本での正確な金額は登録画面で確認） |
| 更新 | 毎年。更新しないと、配布したテスト用アプリが使えなくなります |
| 個人・組織の差 | 年会費は同じ |

### 2-3. 名義の比較

| 項目 | 個人名義 | 組織（法人）名義 |
|---|---|---|
| 必要なもの | Apple アカウント（2ファクタ認証）、本人確認 | 法人格、**D-U-N-S 番号**（無料で取得可能、発行まで数日〜数週間）、法人の代表権または権限の確認 |
| App Store の「販売元」表示 | **個人の氏名** | 法人名 |
| 開発・テスト配布（TestFlight 等） | 可能 | 可能 |
| 登録の早さ | 早い | D-U-N-S 番号取得の分だけ遅い |
| 向いている段階 | PoC の開発・検証 | 施設向けサービスとして一般公開 |

**個人→組織への変更**：Apple の会員情報の画面から組織への切り替えを申請できると、複数の第三者の手順解説で案内されています（創業者等であること・D-U-N-S 番号が必要、審査あり）。ただし、切り替え後も既存アプリの販売元表示が変わらなかったという報告もあり、**Apple 公式の手順は未確認**です。

### 2-4. 提案

| 案 | 内容 | 向いているケース |
|---|---|---|
| 案A（推奨） | **PoC 期間は個人名義で登録**し、一般公開の前に組織名義で登録し直す（または切り替え申請） | すぐに BLE 検証を始めたい。公開時期はまだ先 |
| 案B | 最初から組織名義で登録（D-U-N-S 番号を先に取得） | 法人が既にあり、販売元の名義を最初から揃えたい |
| 案C | 登録を保留し、Expo Go で確認できる開発（Phase 2 の地図・検索・経路・管理画面）を先に進める | 費用発生をさらに遅らせたい。BLE の実機検証は後回しでよい |

## 3. BLE発信機（ビーコン）

### 3-1. 段階的な購入計画（設計書 6-3）

| 段階 | 台数 | 目的 | 時期 |
|---|---|---|---|
| ステップ1 | **1台** | iPhone で電波強度が取れるか、揺らぎ・更新間隔を確認 | Phase 1B |
| ステップ2 | 合計3〜5台 | 測位方式の比較、設置間隔（5 / 7.5 / 10m）と精度の関係を測定 | Phase 3 |
| ステップ3 | ― | 結果から施設用の台数・費用を見積もり、再度判断 | Phase 3 後 |

### 3-2. 機種の選定条件

| 条件 | 理由 | 必須度 |
|---|---|---|
| iBeacon 形式に対応 | iPhone で確実に受信できる形式 | 必須 |
| **技適マークあり** | 日本国内で電波を出す機器に必要 | 必須 |
| 送信間隔・送信出力を設定できる | 測位精度と電池寿命の調整 | 必須 |
| 電池交換可能 | 長期設置のため | 推奨 |
| 電池残量を通知する機能 | 稼働管理が楽になる（ない場合も運用できる設計にしています） | 任意 |
| 3台以上まとめ買いの条件がない、または許容できる | ステップ1は1台で十分 | 推奨 |

### 3-3. 候補（調査時点の情報。在庫・価格は要確認）

| 候補 | 技適 | 価格の参考 | 備考 |
|---|---|---|---|
| アプリックス「MyBeacon」シリーズ | 取得済み（メーカー記載） | 発売当時の記事で 1台 1,800円 の紹介あり（**古い情報**。現在価格は要確認） | 国内メーカー。iBeacon 対応 |
| オカベマーキングシステムの BLE ビーコン（NTT-X Store 取扱い） | 取得済み（販売ページ記載） | 例：約6,200円〜9,600円（税込）。**3個からの注文**（MOQ3個）、調査時点で在庫切れ表示あり | 単3電池式など。iBeacon 仕様 |
| Minew 等の海外メーカー | 機種ごとに要確認 | 問い合わせ形式 | 技適のない機種は国内で使用不可 |
| 小型マイコン基板（ESP32 系、技適取得済みモジュール搭載品） | モジュールが取得済みの製品に限る | 約1,000〜2,000円＋USB電源 | **開発検証専用**（施設設置には不向き）。設定に多少の作業が必要 |

**推奨**：ステップ1は「技適取得済み・iBeacon 対応・1台から買える市販ビーコン」1台（目安 2,000〜5,000円）。購入前に Claude が最新の在庫・価格・仕様を再確認し、候補を1つに絞って提示します。

### 3-4. 設置方法（ステップ1・2）

- 場所：ご自宅や事務所の一室・廊下（家具が少なく、5〜10m の直線がとれる場所が理想）
- 高さ：床から 2〜2.5m（棚の上や壁の高い位置。両面テープで仮固定）
- 金属面に直接貼らない（電波が弱くなる）
- 設置位置をメジャーで測って記録（Claude が記録用の表を用意します）
